# NVNM Frontend Recreation

A frontend reconstruction study inspired by the NVNM Chain landing page.

This project was built to better understand how modern interfaces are structured visually and architecturally through direct recreation and reverse engineering.

## Focus Areas

- Advanced CSS layouts
- Flexbox architecture
- Layering and visual composition
- Atmospheric lighting and glow systems
- Gradients and glassmorphism
- Pseudo-elements
- SVG asset integration

The goal of this project is not simply to reproduce visuals, but to study and understand the systems behind modern frontend interfaces, including:

- layout hierarchy
- composition structure
- lighting systems
- clipping and overflow behavior
- rendering techniques
- reusable UI architecture
